# ZIP-патчи APK Editor / PCompiler

В Lazy Modification добавлены создание, импорт и применение ZIP-патчей, не заменяющие существующие инструменты приложения.

## Применение

1. Откройте «Патчинг» и выберите APK.
2. Нажмите «Патчи APK Editor». Несколько файлов выполняются последовательно.
3. Выберите необходимые встроенные операции и настройки подписи, затем примените изменения.
4. Результат сохраняется через существующий механизм вывода APK. Исходный файл не перезаписывается. Если ни одно правило не изменило APK, отдельный результат не создаётся.

## Создание

«Инструменты» → «Редактор патчей». Можно открыть существующий ZIP или patch.txt, добавить правила через форму, редактировать текст, приложить smali/ZIP/DEX и сохранить совместимый ZIP через системный диалог. Черновик сохраняется в приложении. В редактор включены предоставленные примеры NoAlert и IsPremium V.2 без изменения их правил.

Реализованы MATCH_REPLACE, ADD_FILES, REMOVE_FILES, MATCH_ASSIGN, MATCH_GOTO, GOTO, MERGE, EXECUTE_DEX и DUMMY; метаданные движка 1–2, REGEX/DOTALL, группы ${GROUPn}, переменные, компонентные цели и каталоги нескольких DEX. MERGE принимает ZIP декодированных ресурсов/smali; при добавлении ресурсов нужен res/values/public.xml. EXECUTE_DEX выполняется на Android, интерфейс версии 1, метод с четырьмя строковыми аргументами.

Совпадение патча с конкретной версией приложения не гарантируется: результат зависит от его правил и структуры выбранного APK. Ошибки smali/ресурсов останавливают обработку до сохранения результата. Формат DEX должен поддерживаться smali 2.5.2.

Для APK с очень коротким `versionCode` (1–3 цифры, например `52`) движок временно подменяет его уникальным значением при разборе smali: иначе короткий токен совпадает с тысячами несвязанных констант и патч переписывает почти весь код. В итоговый `AndroidManifest.xml` записывается новое значение из `PARAM`.

Новые строки интерфейса переведены на русский, английский и болгарский. Диалоги переведены на MaterialAlertDialogBuilder, поля ввода получили общую округлённую рамку, программные флажки и переключатели — Material-стиль. Основные экраны, палитра и ресурсы исходного приложения сохранены.

## Сборка

JDK 17 или 21 с компилятором, Android SDK 34, Gradle Wrapper. Укажите sdk.dir в собственном local.properties и выполните ./gradlew assembleRelease. Ключ пользователя в исходники и APK не включён; выпуск подписан отдельно.

По просьбе заказчика эта сборка выдана без запуска тестов и проверки на устройстве. Тестовые сценарии добавлены в исходники для дальнейшей проверки.
